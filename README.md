# 🌱 Eco Sweep AR

An AR game built in Unity 6 using AR Foundation, designed to promote environmental awareness through interactive forest or environment cleanup mechanics.

## 🎯 Features
- Plane detection and object placement
- Touch-based or vanish interaction with trash
- Modular C# scripts for easy expansion
- Built for Android using ARCore

## 🚀 Getting Started
Clone the repo and open in Unity 6. Make sure AR Foundation and ARCore XR Plugin are installed.

## 🛠 Tech Stack
- Unity 6
- AR Foundation
- ARCore XR Plugin
- GitHub for version control
